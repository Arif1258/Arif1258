## About Me

I'm a full-stack developer with a strong foundation in **Data Structures
& Algorithms (Java)** and hands-on, production-adjacent experience
across **backend systems, distributed messaging, and cloud deployment**.
My work spans three internships, each pushing into a different corner of
software engineering --- AI-driven platforms, financial compliance, and
applied cybersecurity --- which has given me a broad view of how real
systems are built, secured, and scaled.

I care about the parts of engineering that don't show up in a demo: how
a system behaves under load, how services communicate reliably, and how
a codebase stays maintainable as a team grows. That's part of why I've
leaned into distributed systems tooling (Kafka, RabbitMQ, Redis) and
containerized deployment (Docker, Kubernetes) alongside the conventional
full-stack skill set.

## Featured Projects

### Full-Stack & Marketplace Systems

**🍔 BiteDash** --- A multi-vendor food marketplace and delivery
platform supporting multiple restaurant vendors on a single system.
Built with React on the frontend and a Node.js/Express backend, using
MongoDB for data storage, RabbitMQ for asynchronous order-processing
workflows, Redis for caching, and Socket.io for real-time order tracking
and live updates between customers, vendors, and delivery agents.

**🚚 DeliveryHub** --- A full-stack food delivery platform where users
can browse restaurants, place orders, and track deliveries in real time.
Focused on a smooth end-to-end ordering experience with live status
updates as an order moves from placed to delivered.

**📦 Nila-Delivery** --- A full-stack delivery management platform built
to streamline order processing, shipment tracking, and delivery
operations, with an emphasis on giving operators a clear, modern view
into logistics status.

### AI & Automation

**🤖 AI Inventory Management Agent** --- An automated agent that manages
inventory workflows end-to-end, built using n8n for orchestration,
OpenAI for intelligent decision-making, and Airtable as the underlying
data store. Designed to reduce manual inventory tracking by handling
routine restocking and reporting logic.

**💬 SigmaGPT** --- An AI chat platform powered by GPT models, wrapped
in a modern, user-friendly interface. Built to explore how LLM-backed
chat experiences can be made more responsive and pleasant to use.

**🎬 Movie Recommendation System** --- A recommendation engine that
suggests movies based on user preferences, using collaborative filtering
and other recommendation algorithms to surface relevant content.

### Security, Compliance & Infrastructure

**🛡️ OFAC List Checking Platform** --- A compliance web application for
checking entities against OFAC sanctions lists, with a PHP backend and
MySQL database, deployed across AWS and Hostinger. Figma was used for
interface design and Visual Paradigm for system modeling, with testing
performed manually given the absence of a CI/CD pipeline on this
project.

**📹 SpaceCall** --- A real-time video conferencing platform built using
WebRTC for peer-to-peer video/audio and Socket.io for signaling and
real-time coordination between participants.

**⚡ AetherMonitor** --- A website monitoring platform that tracks
uptime, performance, and service availability, with real-time status
updates and incident reporting to help catch issues as they happen.
